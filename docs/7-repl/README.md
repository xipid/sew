# Sew REPL

Sew features a lightweight, blazingly fast, and interactive REPL (Read-Eval-Print Loop) environment. It allows evaluating Javascript (using QuickJS) and Python (using QuickJS and Python environments) with full access to reflected C++ objects and methods dynamically.

## Sub-categories

- [Usage & Interactive Mode](usage.md): Command line interface flags, interactive REPL features, and stdin piping.
- [Integration & Native Libraries](integration.md): Compiling and linking with precompiled C++ static archives (e.g. `libXylem.a`) to run database operations and C++ engines directly inside the JS REPL.
